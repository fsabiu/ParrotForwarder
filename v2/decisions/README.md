# Decisions (ADRs)

Architecture Decision Records. One file per decision, numbered sequentially. Format is Michael Nygard's classic: Context, Decision, Consequences.

## Process

- Open as `proposed` when you need input.
- Move to `accepted` once the team signs off.
- Never edit an accepted ADR in place. If a decision changes, supersede with a new ADR referencing the old one.
